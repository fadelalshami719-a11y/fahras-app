## ✨ المميزات الرئيسية
- **تخزين محلي فائق السرعة:** يعمل بدون إنترنت عبر `LocalStorage` مع بحث فوري وتصفية حسب التصنيفات والمفضلة.
- **مزامنة سحابية آمنة (Google Drive):** حفظ واستعادة تلقائية للنسخ الاحتياطية داخل مجلد التطبيق المخفي (`appDataFolder`) دون الوصول إلى أي ملفات أخرى في حسابك.
- **إحصائيات تفاعلية:** رسوم بيانية توضح توزيع الروابط وأكثر المواقع زيارة.
- **تصميم متجاوب بالكامل:** يدعم الوضع الداكن والنهاري ويعمل بسلاسة على الحاسوب والهاتف.

## Overview (English — For Google OAuth Verification)
**Fihris (فِهرِس)** is a free, open-source, non-commercial bookmark manager hosted on GitHub Pages. It operates strictly client-side and optionally uses the restricted `drive.appdata` scope to sync a personal JSON backup file (`fahras_backup.json`) in the user's own Google Drive.
- **Home Page:** `https://fadelalshami719-a11y.github.io/fahras-app/`
