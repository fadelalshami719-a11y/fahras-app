Fihris (فِهرِس) — Smart Personal Bookmark Manager

Fihris (فِهرِس) هو تطبيق ويب مجاني لحفظ وتنظيم الروابط، التصنيفات، والمفضلات محلياً في متصفحك مع إحصائيات استخدام فورية، دون الحاجة لتسجيل الدخول. تسجيل الدخول عبر Google اختياري تماماً ويُستخدم فقط لنسخ روابطك احتياطياً في مجلد التطبيق المخفي على Google Drive (drive.appdata).
About Fihris: Fihris is a free, client-side bookmark manager that lets users save, categorize, search, and analyze bookmarks locally with no login required. Optional Google Sign-In uses only the restricted drive.appdata scope to store and restore your personal backup file (fahras_backup.json) in your own Google Drive, in full compliance with the Google API Services User Data Policy.
